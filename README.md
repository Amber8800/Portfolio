# 황호순 · ML / AI 포트폴리오

함교 콘솔에서 중앙 항성과 세 프로젝트의 궤도가 홀로그램으로 떠오릅니다. 행성을 선택하면 홀로그램 속 카메라가 1.5초 동안 그 행성으로 이동합니다. 가장 안쪽의 두잎으로 다가가면 바깥 궤도는 투사 영역을 가로지르는 큰 호로 보이고, 외곽의 VISHUE로 돌아가면 더 넓은 항성계가 보입니다. 행성은 제자리에서 자전합니다.

탭에서 처음 홈을 열면 어두운 함교에 접속 코드가 입력됩니다. 화면 중앙에서 `접속 승인`이 `WELCOME`으로 바뀝니다. 환영 문구가 떠 있는 동안 하단의 램프 8개와 천장 램프 2개가 하나씩 켜지고 창 셔터가 올라갑니다. 콘솔에서 투사광이 올라오면 항성과 궤도, 안쪽부터 바깥쪽 행성 순서로 나타납니다. 행성 HUD가 켜지면 이름과 탐색 링크, 프로젝트 선택 제목과 각 버튼이 순서대로 점등됩니다. 첫 브리핑은 HUD가 그려진 후 연결선과 타이핑을 거쳐 열립니다. 데스크톱에서는 글자가 끝까지 써지기까지 약 7초가 걸립니다. 건너뛰기·Esc·프로젝트 선택은 연출 중에도 작동합니다. 상세 링크로 들어오거나 모션 감소 또는 모션 멈춤을 설정한 경우에는 곧바로 콘텐츠를 표시합니다.

행성이 도착하면 앰버 HUD의 두 호가 오른쪽에서 시작해 왼쪽에서 만납니다. 그 접점에서 브리핑으로 연결선이 뻗고 글자가 써집니다. 약 80%를 썼을 때 서비스 화면과 상세 버튼이 함께 한 번 깜빡입니다. 상세 버튼이나 이동 중의 상단 바로가기를 누르면 함교 위에 해당 프로젝트의 브리핑 문서가 열립니다. 닫기·Esc·뒤로가기로 읽던 행성에 돌아옵니다. 창업ON의 3차·4차는 한 버튼 안의 이중 행성입니다. 헤더의 이력서에서 고른 문서를 닫으면 이력서로 돌아옵니다.

## 로컬 실행

Python 3.11 이상과 uv를 사용합니다. 프로젝트 루트에서 실행하세요.

```powershell
uv sync --locked
uv run --locked python scripts/build.py
uv run --locked python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

미리보기 주소는 <http://127.0.0.1:4173/>입니다. 원본을 수정한 뒤 빌드를 다시 실행하고 브라우저를 새로고침하면 됩니다.

[첫 진입 연출 다시 보기](http://127.0.0.1:4173/?intro=replay)

## 콘텐츠 수정

- `content/profile.toml`에서 이름, 직무, GitHub와 이력서 기술 목록을 편집합니다.
- `content/projects/*.toml`에서 프로젝트 소개, 역할, 기술 결정, 결과와 출처를 편집합니다. 홈·상세·이력서가 같은 프로젝트 원본을 읽습니다.
- 실제 서비스 화면과 로고는 `assets/projects/<slug>/`에 둡니다. TOML의 `media`에서 원본의 크기, 대체 텍스트, 캡션, 출처를 지정합니다. 화면 또는 로고가 없을 때는 해당 키를 생략하면 그 영역이 접힙니다.
- 각 프로젝트 TOML의 `orbit.radius`는 홀로그램 속 궤도 반경이고, `orbit.focus_zoom`은 카메라 도착 시 행성의 배율입니다. 함교·우주·행성 텍스처는 `assets/bridge/`, 항로는 `templates/components/routes.svg`에 있습니다. 첫 화면의 좌표는 `scripts/build.py`에서 계산합니다. 이동할 때는 `assets/css/bridge.css`에서 같은 카메라 거리와 시선으로 HTML 행성, 항성, SVG 궤도를 함께 투영합니다. 대기 중의 표면 자전, 별 흐름과 링은 모션 버튼으로 함께 멈출 수 있습니다.

## 고정 상세 주소

| 프로젝트 | 경로 |
| --- | --- |
| VISHUE | `/projects/vishue/` |
| 창업ON · 3차와 4차 | `/projects/changup-on/` |
| 두잎 | `/projects/duip/` |

각 경로에는 자체 `index.html`이 있습니다. 이력서와 외부 문서에서 해당 주소를 직접 연결할 수 있습니다. 함교 위에 열린 문서도 주소를 공유할 수 있습니다. 예를 들어 `/?project=duip#briefing`은 두잎 문서가 열린 함교로 바로 연결됩니다.

## 자료 출처

프로젝트별 팀 저장소와 공개 시연, 실험 조건은 각 상세와 프로젝트 TOML에 연결했습니다. VISHUE의 제품 추천 화면은 팀 검증용 테스트 데이터입니다. 재현율 비교는 같은 사람 단위 테스트 분할에서 모공 전처리 조건을 바꾼 실험입니다.

VISHUE의 버건디는 서비스 화면의 버튼색에서, 창업ON 이중 행성의 파랑과 초록은 로고에서 가져왔습니다. 두 프로젝트의 지형에는 Solar System Scope / INOVE의 Moon과 Venus Surface 지도를 사용했습니다. 두잎의 상록 숲·바다 지도와 창밖의 별 배경, 함교 프레임은 ImageGen으로 제작했습니다. 각 페이지 하단에서 이미지 출처와 라이선스를 볼 수 있습니다. Barlow의 배포 라이선스는 `assets/fonts/OFL-Barlow.txt`에 포함되어 있습니다.
